#  Página de Venda de Passeios

Uma landing page moderna e responsiva desenvolvida para a comercialização de pacotes turísticos e passeios. O projeto foca em uma interface intuitiva, carregamento rápido e uma experiência de utilizador otimizada para conversão.

##  Funcionalidades

- **Catálogo de Passeios:** Exibição detalhada de destinos com imagens e descrições.
- **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
- **Seção de Prova Social:** Depoimentos de clientes para aumentar a confiabilidade.
- **Formulário de Contacto/Reserva:** Integração simples para captação de leads.
- **Botões de Call-to-Action (CTA):** Estrategicamente posicionados para guiar o utilizador à compra.

##  Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web front-end:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização personalizada e layouts com Flexbox/Grid.
- **JavaScript:** Interatividade e animações leves.
- **Google Fonts:** Tipografia moderna para melhor legibilidade.
